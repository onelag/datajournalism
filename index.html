⚙️ Workflow

The Investigative Pipeline

From raw chaos to front-page impact

Phase 1: Ingestion & Scraping

Automated scripts monitor public registries, government procurement feeds, and court dockets.

Phase 2: Cleaning & Verification

Standardizing dates, de-duplicating entities, checking outliers, and cross-referencing sources.

Phase 3: Statistical Analysis

Hypothesis testing, spatial GIS clustering, and regression models to separate noise from anomaly.

Phase 4: Editorial Visualization

Interactive maps, charts, and scrollytelling experiences tailored for both mobile and desktop.

Walk through the 4 steps: - Most time (70-80%) is spent in Phase 1 and 2: Cleaning and verifying. - Always emphasize that data must be verified with on-the-ground human interviews.
💻 Code As A Reporting Tool

Reproducible Investigations

Writing code ensures audits can be peer-reviewed by readers and editors


import pandas as pd
import geopandas as gpd

# Load public contracts dataset
contracts = pd.read_csv("https://data.gov/procurement_2026.csv")

# Filter for emergency sole-source allocations
unbid_contracts = contracts[
    (contracts['bidding_type'] == 'emergency_direct') & 
    (contracts['amount_usd'] > 1_000_000)
]

print(f"Discovered {len(unbid_contracts)} unbid contracts requiring investigation.")
